dev-claw

AI-powered SDLC automation for the terminal

Type what you want in plain English — or use structured commands. Bring your own key. Works with 8+ LLM providers. Every phase of the dev workflow, from broken build to shipped release.

Quick Start

Three steps to your first AI-assisted commit.

shell
# 1. Install
curl -fsSL https://akkeshavan.github.io/dev-claw/install.sh | sh

# 2. Add an API key — pick any provider
dev-claw config set-key --provider deepseek   # cheapest
dev-claw config set-key --provider openai     # most capable
dev-claw config set-key --provider ollama     # local, no key needed

# 3. Start automating — structured commands...
cargo build 2>&1 | dev-claw doctor   # diagnose a build error
dev-claw git commit                   # AI-written commit message
dev-claw standup                      # today's standup from git

# ...or just say what you want
dev-claw git "squash last 3 commits and open a PR"
dev-claw "review staged changes and if clean commit and push"
New Natural Language Interface

Just describe what you want

dev-claw maps your intent to the right tool sequence, shows you the plan, and waits for your confirmation before running anything.

Scoped mode ~150 tokens · recommended

Prefix with a namespace. The planner only sees that domain's tools — cheaper, faster, and more focused. Use this for anything within a single area.

$ dev-claw git "squash last 3 commits and open a PR"
$ dev-claw git "sync with main and resolve any conflicts"
$ dev-claw review "check staged changes for security issues"
$ dev-claw deps "audit and triage anything critical"
$ dev-claw release "draft notes and cut v2.0.0"
Global mode ~600 tokens · cross-domain

No namespace prefix. The planner sees all 40+ tools across every domain. Use this only for workflows that genuinely cross multiple areas — it sends more tokens.

$ dev-claw "review staged changes and if clean commit and push"
$ dev-claw "sync with main, resolve conflicts, then push"
$ dev-claw "audit deps, draft release notes, and cut v1.5.0"
Global mode prints a cost reminder to stderr so you're never surprised by token usage.

Commands

Structured commands for when you want predictable, explicit control.

Debugging

dev-claw doctor

Pipe any build log, compiler error, or crash dump and get a one-shot root cause + fix. No preamble, no filler — just the diagnosis.

cargo build 2>&1 | dev-claw doctor
npm run build 2>&1 | dev-claw doctor
cat ci-failure.log | dev-claw doctor

Git

dev-claw git commit

Generate a conventional commit message from your staged diff. Reads context from project memory to stay consistent with your style.

git add -p && dev-claw git commit
dev-claw git branch

Generate a branch name from a plain-English description. Use --apply to immediately run git checkout -b.

dev-claw git branch "add dark mode toggle"
dev-claw git branch "fix login timeout" --apply
dev-claw git squash

Squash the last N commits into one with an AI-generated message. Preview first, then pass --apply to run the reset and commit.

dev-claw git squash 3
dev-claw git squash 3 --apply
dev-claw git push

Smart push that sets upstream if missing, guards for leaked secrets, and supports force-push with --force-with-lease — safer than bare --force.

dev-claw git push
dev-claw git push --force
dev-claw git pr

Draft a pull request description from commits on your branch. Add --create to push the branch and open the PR via the gh CLI in one shot.

dev-claw git pr
dev-claw git pr --create
dev-claw git pr --create --base develop
dev-claw git resolve

AI-assisted merge conflict resolution. Shows each conflict with both sides, suggests a resolution, and confirms before writing to disk.

git merge feature/x    # produces conflicts
dev-claw git resolve   # resolve each with AI
dev-claw git sync

Fetch origin and rebase the current branch onto origin/<base>. Automatically resolves any conflicts that arise during the rebase.

dev-claw git sync
dev-claw git sync --base develop
dev-claw git log

AI narrative summary of recent commits. Choose a plain, Slack-formatted, or Markdown output for different audiences.

dev-claw git log --since "2 days ago"
dev-claw git log --since v1.2.0 --format slack
dev-claw git rebase

AI interactive-rebase plan for the last N commits. Writes the todo list, launches git rebase -i with the plan already filled in.

dev-claw git rebase 5
dev-claw git stash

Stash changes with an AI-generated description, or pass your own message. Cleaner than git stash with no message.

dev-claw git stash
dev-claw git stash --message "WIP: auth refactor"
dev-claw git cherry-pick

Cherry-pick a commit by SHA. If conflicts arise, dev-claw resolves them with AI the same way resolve does.

dev-claw git cherry-pick abc1234
dev-claw git check / hook

Scan staged changes for blocked keywords before committing. hook installs this as a git pre-commit hook so it runs automatically.

dev-claw git check
dev-claw git hook

Code Review

dev-claw review diff

Review staged or unstaged changes before committing. Focus on security, performance, or style with --focus.

dev-claw review diff --staged
dev-claw review diff --focus security
dev-claw review pr

Review a GitHub PR by number. Fetches the full diff and provides structured feedback from your configured LLM.

dev-claw review pr 142
dev-claw review pr 142 --focus style

Code Intelligence

dev-claw forensic explain

Explain what a file does using its full git history, blame data, and source. Answers "why does this exist?" for inherited code.

dev-claw forensic explain src/auth.rs
dev-claw forensic explain src/auth.rs --lines 40-80
dev-claw forensic blame

Trace why a specific line of code exists — which commit introduced it and what problem it was solving at the time.

dev-claw forensic blame src/api.rs:87

Environment & Security

dev-claw env check

Diff .env against .env.example — report missing, empty, or extra keys. Catches config drift before it reaches production.

dev-claw env check
dev-claw env guard

Scan staged changes for secrets about to be committed. Blocks the commit if anything looks like an API key or password.

dev-claw env guard
dev-claw env hook

Install pre-commit (guard) and post-checkout (check) git hooks automatically — so env protection runs without thinking about it.

dev-claw env hook

Dependencies

dev-claw deps audit

Run security audits across all detected package managers (Cargo, npm, Go, pip) in one shot. Add --triage for an AI-ranked action list: fix now vs. later vs. ignore.

dev-claw deps audit
dev-claw deps audit --triage
dev-claw deps outdated

Check for outdated dependencies across all detected package managers simultaneously — no switching tools per ecosystem.

dev-claw deps outdated

Test Data

dev-claw mock gen

Generate realistic fixture data from a type definition or schema. Outputs JSON, YAML, or SQL seed data ready for your test suite.

dev-claw mock gen schema.sql --count 20 --format sql
dev-claw mock gen types.ts --format json --out fixtures.json
dev-claw mock factory

Scaffold a factory function for a given type — correctly typed, ready to paste into your test helpers.

dev-claw mock factory src/types/user.ts --out src/__tests__/factories.ts

dev-claw release notes

Draft human-readable release notes from git commits since the last tag. Ready to paste into GitHub Releases.

dev-claw release notes
dev-claw release notes --since v1.1.0
dev-claw release cut

Write CHANGELOG.md and create an annotated git tag in one step. Prompts before anything is written to disk.

dev-claw release cut v1.2.0

Cloud VMs

dev-claw cloud

Spin up and tear down ephemeral dev VMs across AWS, GCP, Azure, and Fly.io. Destroy requires explicit confirmation — nothing is deleted silently.

dev-claw cloud up --provider aws --size small
dev-claw cloud ls
dev-claw cloud ssh my-vm
dev-claw cloud down my-vm

dev-claw memory ls

Power Users

Advanced patterns for teams who want deeper automation, tighter control, and zero repetitive decisions.

Automation Workflows in .devclawrc

Define reusable multi-step workflows in your project config. Run them by name, share them as a Gist, import from a team member.

.devclawrc
[[workflows]]
name  = "pre-push"
steps = [
  "dev-claw env check",
  "dev-claw review diff --staged",
  "dev-claw deps audit",
]

[[workflows]]
name  = "ship"
steps = [
  "dev-claw deps audit --triage",
  "dev-claw release notes",
  "dev-claw release cut",
]
dev-claw workflow run pre-push
dev-claw workflow run ship
dev-claw workflow publish pre-push     # → GitHub Gist
dev-claw workflow import gist:abc123  # ← team member's gist

Git Automation Chains

Combine git subcommands into complete workflows — either as shell pipelines or via the NL interface for complex multi-step operations.

shell
# Full feature branch cycle
dev-claw git branch "add payment webhook" --apply
git add -p
dev-claw git commit
dev-claw git push
dev-claw git pr --create

# Tidy up before a review
dev-claw git squash 4 --apply

# Catch up with main
dev-claw git sync --base main

# Or just say it
dev-claw git "squash 4 commits, sync with main, and create a PR"

Token Optimization

Control which provider and model are used per-session, per-project, or per-invocation. Cheap providers for routine tasks, powerful ones for deep analysis.

shell
# Force a specific provider for this session
export DEV_CLAW_PROVIDER=deepseek   # cheapest
export DEV_CLAW_PROVIDER=groq       # fastest

# One-off with a different provider
DEV_CLAW_PROVIDER=anthropic dev-claw forensic explain src/core.rs

# Use a generic key for all providers
export DEV_CLAW_API_KEY=sk-...

# Keep NL cheap: use scoped mode for single-domain work
dev-claw git "..."      # ~150 tokens
# not:
dev-claw "..."          # ~600 tokens — only for cross-domain

Persistent Project Memory

Teach dev-claw about your project once. Notes and feedback are injected into every LLM prompt so you stop repeating context.

shell
# One-time setup for a new project
dev-claw memory note "postgres 16 with pgvector extension"
dev-claw memory note "all API routes live in src/api/"
dev-claw memory note "we use kebab-case for branch names"

# Tune LLM output over time
dev-claw memory feedback "prefer concise responses" --command standup
dev-claw memory feedback "always include file paths" --command review

# Inspect what's stored
dev-claw memory ls

Memory is stored in .dev-claw/memory.toml (gitignored automatically) and synced to a local SQLite database for cross-session access.

Monthly Quota Controls

Set per-command and total monthly limits to keep free-tier usage in check. dev-claw warns before you hit the cap and blocks once you do.

.devclawrc
[usage]
monthly_limit   = 200   # total invocations/month
doctor_limit    = 75    # per-command caps
git_limit       = 60
forensic_limit  = 50
mock_limit      = 30
cloud_limit     = 3
warn_at_percent = 80    # warn when 80% used
dev-claw usage   # see current month's breakdown

Custom Keyword Blocks

Extend the default blocked-keyword list to catch project-specific patterns — internal function names, TODO tags, placeholder strings — before they reach a PR.

.devclawrc
[git]
block_on_keywords = [
  "console.log",
  "debugger",
  "TODO",
  "FIXME",
  "INTERNAL_SECRET",
  "test-api-key",
]
dev-claw git check   # scans staged diff for these patterns
dev-claw git hook    # runs automatically on every commit

CI Integration

Use dev-claw in CI pipelines for automated review, security audits, and release automation. Set credentials via environment variables — no passphrase prompt in non-interactive mode.

GitHub Actions
- name: Install dev-claw
  run: curl -fsSL https://akkeshavan.github.io/dev-claw/install.sh | sh

- name: Security audit
  env:
    DEV_CLAW_API_KEY: ${{ secrets.DEEPSEEK_KEY }}
    DEV_CLAW_PROVIDER: deepseek
  run: dev-claw deps audit --triage

- name: Review PR diff
  env:
    DEV_CLAW_API_KEY: ${{ secrets.OPENAI_KEY }}
  run: dev-claw review pr ${{ github.event.pull_request.number }}
