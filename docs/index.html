dev-claw

AI-powered SDLC automation for the terminal

Bring your own key. Works with 8+ LLM providers. 14 commands covering the full dev workflow — from a broken build to a shipped release.

$ curl -fsSL https://akkeshavan.github.io/dev-claw/install.sh | sh
Open Source BYOK Rust MIT License 8+ LLM Providers

Quick Start

Three steps to your first AI-assisted commit.

shell
# 1. Install
curl -fsSL https://akkeshavan.github.io/dev-claw/install.sh | sh

# 2. Add an API key — pick any provider
dev-claw config set-key --provider deepseek   # cheapest
dev-claw config set-key --provider openai     # most capable
dev-claw config set-key --provider ollama     # local, no key needed

# 3. Start automating
cargo build 2>&1 | dev-claw doctor   # diagnose a build error
dev-claw git commit                   # AI-written commit message
dev-claw standup                      # today's standup from git

# Note: dev-claw git commit generates the message but uses your existing
# git setup for the actual commit. Git must be configured first:
# git config --global user.name "Your Name"
# git config --global user.email "you@example.com"

Commands

14 commands covering the full software development lifecycle.

Debugging

dev-claw doctor

Pipe any build log, compiler error, or crash dump and get a one-shot root cause + fix. No preamble, no filler — just the diagnosis.

cargo build 2>&1 | dev-claw doctor
npm run build 2>&1 | dev-claw doctor
cat ci-failure.log | dev-claw doctor

Git

dev-claw git commit

Generate a conventional commit message from your staged diff. Reads context from project memory to stay consistent with your style.

git add -p && dev-claw git commit
dev-claw git pr

Draft a pull request description from the commit history on your current branch versus main. Copy-paste ready.

dev-claw git pr
dev-claw git hook

Install a pre-commit git hook that automatically runs env scanning and review before every commit.

dev-claw git hook --install

Code Review

dev-claw review diff

Review staged or unstaged changes before committing. Catches bugs, security issues, and style problems before they land.

dev-claw review diff --staged
dev-claw review pr

Review a GitHub PR by number. Fetches the full diff and provides structured feedback from your configured LLM.

dev-claw review pr 142

Code Intelligence

dev-claw forensic explain

Explain what a file does using its full git history, blame data, and source. Answers "why does this exist?" for inherited code.

dev-claw forensic explain src/auth.rs
dev-claw forensic blame

Trace why a specific line of code exists — which commit introduced it and what problem it was solving at the time.

dev-claw forensic blame src/api.rs:87

Environment & Security

dev-claw env check

Scan for missing environment variables, exposed secrets in tracked files, and misconfigured .env setups.

dev-claw env check
dev-claw env guard

Wrap any command with env enforcement — fails fast if required variables are missing before the process starts.

dev-claw env guard -- npm run deploy
dev-claw env hook

Install a git pre-commit hook that scans for accidental secret exposure before every commit, automatically.

dev-claw env hook --install

Dependencies

dev-claw deps audit

Run security audits across all detected package managers (Cargo, npm, Go, pip) in one shot. Add --triage for an AI-ranked action list: fix now vs. later vs. ignore.

dev-claw deps audit
dev-claw deps audit --triage
dev-claw deps outdated

Check for outdated dependencies across all detected package managers simultaneously — no switching tools per ecosystem.

dev-claw deps outdated

Test Data

dev-claw mock gen

Generate realistic fixture data from a type definition or schema. Outputs JSON, YAML, or SQL seed data ready for your test suite.

dev-claw mock gen --schema types/User.ts
dev-claw mock factory

Scaffold a factory function for a given type — correctly typed, ready to paste into your test helpers.

dev-claw mock factory --type Order

Releases & Standups

dev-claw standup

Generate daily standup bullet points from git history. Covers what you shipped, nothing more — no padding.

dev-claw standup --since yesterday
dev-claw standup --since "last friday"
dev-claw release notes

Draft human-readable release notes from git commits since the last tag. Ready to paste into GitHub Releases.

dev-claw release notes
dev-claw release cut

Write CHANGELOG.md and create a signed git tag in one step. Requires confirmation before anything is written to disk.

dev-claw release cut v1.2.0

Cloud VMs

dev-claw cloud

Spin up and tear down ephemeral dev VMs across AWS, GCP, Azure, and Fly.io. Destroy requires explicit confirmation — nothing is deleted silently.

dev-claw cloud up --provider aws --size small
dev-claw cloud ls
dev-claw cloud ssh my-vm
dev-claw cloud down my-vm

Automation Workflows

dev-claw workflow

Define multi-step automation in TOML, run it locally, and share via GitHub Gist. Shell-safe argument splitting, 50-step safety cap, no arbitrary remote execution.

dev-claw workflow run deploy.toml
dev-claw workflow publish deploy.toml
dev-claw workflow import gist:abc123def

Memory & Config

dev-claw memory

Per-project memory that persists across sessions. dev-claw learns your stack and preferences, injecting context into every LLM call for better answers over time.

dev-claw memory note "using postgres 16, pgvector"
dev-claw memory feedback "prefer short responses"
dev-claw memory ls
dev-claw config / usage

Manage API keys for all providers. Keys are encrypted with AES-256-GCM and stored only on your machine — never sent to any server. Track token quota with usage.

dev-claw config set-key --provider anthropic
dev-claw config list-keys
dev-claw usage

Use Cases

How dev-claw fits into your actual day.

🔍

Debug CI faster

Download the failing log and pipe it in. Get root cause + a copy-pasteable fix in under 10 seconds, no scrolling through 2 000 lines.

cat ci-failure.log | dev-claw doctor
📝

Commit without context-switching

Stage your changes, let dev-claw write the message. Conventional commits, properly scoped, every time — without opening a browser to remember the format.

git add -p
dev-claw git commit
☀️

Monday morning standup

Never blank on what you shipped last week. dev-claw reads your git history and writes your standup points — just edit and send.

dev-claw standup --since "last friday"
🔒

Pre-push safety check

Run the full gauntlet before pushing: env scan, staged diff review, and dependency audit chained together.

dev-claw env check \
  && dev-claw review diff --staged \
  && dev-claw deps audit
🧬

Understand inherited code

Dropped into an unfamiliar codebase? Explain a file's purpose from its full git history, then trace exactly why a suspicious line was added.

dev-claw forensic explain src/legacy.rs
dev-claw forensic blame src/legacy.rs:204
🚀

Ship a release end-to-end

From security audit to changelog to signed tag — three commands, confirmation required before anything is written.

dev-claw deps audit --triage
dev-claw release notes
dev-claw release cut v2.0.0

Install

curl installer (recommended)

Auto-detects your OS and architecture. Verifies SHA-256 checksum before installing. Works on macOS and Linux.

curl -fsSL https://akkeshavan.github.io/dev-claw/install.sh | sh

To pin a version: VERSION=v0.1.0 curl -fsSL ... | sh
